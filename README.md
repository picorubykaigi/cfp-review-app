# CFP Review App

PicoRubyKaigi 2026 Assemble のプロポーザルレビューに使う [Funicular](https://github.com/picoruby/funicular)（PicoRuby.wasm） 製の静的アプリです。  
データソースは Google フォームで、応募受付ほか採否の決定、登壇者への通知、タイムテーブル機能はありません。


## レビュアーの使い方

配られたリンクを開いて「Google でサインイン」をクリックすると、初回のみ「このアプリは Google で確認されていません」と表示されます。「詳細」→「(アプリ名) に移動」で進んでください。

一覧からプロポーザルを開き、1〜5の点数を付けて保存します。  
自分が採点して保存すると、ほかの人の採点とコメントが見えるようになります。

自分のプロポーザルも一覧に出ますが、採点はできません。ほかの人の点数は見えますが、コメントは見えません。

プロポーザルにはタグを付けられます。

## ローカルで動かす

```
ruby -run -e httpd . -p 8917
```

- <http://localhost:8917/dev.html>
  - テストデータ。OAuth 不要
- `http://localhost:8917/#<シートID>`
  - 本番データ。要サインイン

シートIDは URL のフラグメントで渡します。localStorage に保存するので2回目以降はドメインのみで開きます。

## セットアップ

### OAuth クライアントID

[Google Cloud コンソール](https://console.cloud.google.com)で作成し、`config.js` の`CFP_CLIENT_ID` に貼ります。非秘匿値なのでコミットして構いません。

1. プロジェクトを作る
2. Google Sheets API を有効にする
3. OAuth 同意画面: ユーザーの種類は External、公開状態はテスト
4. スコープに `auth/spreadsheets` と `auth/userinfo.email` を追加
5. 選考メンバーをテストユーザーに登録する。登録していない人はサインインできない
6. 認証情報 → OAuth クライアントID → ウェブアプリケーション
   - 承認済み JavaScript 生成元に `http://localhost:8917` と公開先のオリジンを登録
   - オリジンのみ。パスや末尾のスラッシュは書けない
   - リダイレクト URI は不要

### Ratings タブ

回答シートに `Ratings` という名前のタブを作ります。

| 列 | 内容 | 例 |
|---|---|---|
| A | タイムスタンプ | `2026-09-01T03:20:11.123Z` |
| B | レビュアー | `reviewer@example.com` |
| C | 対象行 | `5` |
| D | 点数 | `4` |
| E | コメント | 自由記述 |

C列は回答シートの行番号です。

アプリは行の追記のみ行います。同じ人が同じプロポーザルを採点し直すと行が増え、一番下の行が最新になります。

### Tags タブ

回答シートに `Tags` という名前のタブを作ります。

| 列 | 内容 | 例 |
|---|---|---|
| A | タイムスタンプ | `2026-09-01T03:20:11.123Z` |
| B | 編集した人 | `reviewer@example.com` |
| C | 対象行 | `5` |
| D | タグ | `core, 要デモ確認` |

アプリは行の追記のみ行います。対象行ごとに一番下の行がいまのタグです。

### テスト投稿の除外

`proposals.rb` の `TEST_ROWS` に行番号を書くと、テスト行を除外できます。

## 公開する

GitHub Pages を main で有効にします。ビルドステップはありません。
公開先のオリジンを OAuth の承認済み生成元に登録するのを忘れないでください。

`https://<公開先>/#<シートID>` の形式でリンクを配布してください。

## 謝辞

[rubycentral/cfp-app](https://github.com/rubycentral/cfp-app) のプロポーザル選考機能を Funicular で再実装したものです。
